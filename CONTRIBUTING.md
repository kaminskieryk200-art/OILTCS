# Contributing

This project is an early draft. Please run `bash ./run-tests.sh` before proposing changes, explain protocol compatibility and security impact, and add tests for malformed input and resource limits. Do not include credentials, private keys, account data, production APKs, or proprietary material. Contributions to source code are intended to be made under Apache 2.0; contributions to documentation and vectors under CC BY 4.0. Do not contribute material you are not authorized to license.

Tests here are simulated. Changes that claim Android, Bluetooth, Wi-Fi, voice, or security behavior need independent real-device or security evidence; avoid asserting readiness based only on unit tests.
